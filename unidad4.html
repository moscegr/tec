Máquinas de Turing

El modelo computacional absoluto propuesto por Alan Turing. Si un problema puede resolverse computacionalmente, una Máquina de Turing puede hacerlo.

Intro 4.1 Definición 4.2 Construcción Modular 4.3 Lenguajes Aceptados 4.4 Implementación Java

Analogía: La Cinta Infinita

En la Unidad 3 vimos que los AFD no tienen memoria. Solo avanzan leyendo caracteres hacia adelante y no pueden volver atrás ni escribir.

Turing imaginó una máquina que tiene un cabezal lector/escritor montado sobre una cinta infinita. La máquina puede leer un símbolo, borrarlo, escribir uno nuevo y mover el cabezal hacia la Izquierda (L) o Derecha (R). Esto le da el poder de la memoria infinita.

4.1

Definición Formal de la MT

Formalmente, la Máquina de Turing (MT) se define como una 7-tupla matemática: \( M = (Q, \Sigma, \Gamma, \delta, q_0, q_{accept}, q_{reject}) \).

Para no confundirnos con los símbolos griegos, en programación la leeremos con estas "variables" más amigables (ideales para modelarla en un ESP32 o en Java):
MT = (Estados, Alfabeto_Entrada, Alfabeto_Cinta, Reglas, Inicio, Acepta, Rechaza)

Q (Estados) : Conjunto finito de estados.

\(\Sigma\) (Alfabeto_Entrada) : Alfabeto de entrada (sin el símbolo blanco \(\sqcup\)).

\(\Gamma\) (Alfabeto_Cinta) : Alfabeto de la cinta (incluye a \(\Sigma\) y al espacio en blanco \(\sqcup\)).

\(\delta\) (Reglas) : Función de transición. Su formato es: (EstadoActual, SímboloLeído) -> (NuevoEstado, SímboloEscrito, Dirección[L/R])

q_0 (Inicio) : Estado inicial.

q_accept (Acepta) : Estado de aceptación (Si la máquina llega aquí, se detiene y aprueba).

q_reject (Rechaza) : Estado de rechazo (Si la máquina llega aquí, se detiene y falla).

4.2

Construcción Modular

Al igual que en programación no escribimos un bloque gigante de código (usamos funciones), las MT complejas se construyen combinando "sub-máquinas".

  • MT de desplazamiento: Va a la derecha hasta encontrar un espacio en blanco.
  • MT de borrado: Cambia símbolos por espacios.
  • MT copiadora: Duplica una cadena en otra parte de la cinta.

"Piensa como Turing". Responde en libreta:

Imagina que tienes una cinta con `1011`. Quieres invertir los bits para que diga `0100`. Escribe la lógica modular de la transición.
Ayuda: "Si leo un 1, escribo un 0 y me muevo a R (derecha). Si leo un 0, escribo un 1 y me muevo a R. Si leo blanco (\(\sqcup\)), me detengo."

4.3

Lenguajes Recursivamente Enumerables

La MT reconoce la cúspide de la jerarquía de Chomsky (Tipo 0). Cualquier lenguaje que pueda ser reconocido o generado por un algoritmo computacional es "Recursivamente Enumerable".

El Problema de la Parada (Halting Problem): Alan Turing demostró que existen lenguajes/problemas que la MT NO puede resolver. Es imposible escribir un programa general que tome otro código fuente y sepa con certeza absoluta si ese programa terminará algún día o se quedará colgado en un ciclo infinito.
4.4

Implementación en Java

Programar una Máquina de Turing te ayudará a entender las bases de la computación. En Java, simularemos la Cinta Infinita usando un arreglo (char[]) muy grande y el Cabezal será simplemente un índice (int) apuntando a esa memoria.

La Arquitectura Base

1. La Memoria y el Cabezal

Creamos una cinta ficticia con espacios en blanco ('_') y situamos el cabezal al medio para que pueda ir a la izquierda o derecha libremente.

char[] cinta = new char[1000];
java.util.Arrays.fill(cinta, '_'); // Llenar de blancos

int cabezal = 500; // Inicio (Centro)
int estado = 0;    // q0

2. El Bucle de Estados

La MT no usa un bucle for porque puede retroceder. Se usa un bucle infinito while atado a los estados de aceptación (99) o rechazo (-1).

while(estado != 99 && estado != -1) {
    char leido = cinta[cabezal];
    // Lógica de transiciones (switch/if)
    // Escribe -> Mueve (++, --) -> Cambia Estado
}

Ejemplos Completos (Paso a Paso)

Para comprender mejor cómo funciona la máquina, analizaremos programas en Java completos. Observa cómo la combinación de Estado Actual y Símbolo Leído decide el futuro de la transición.

Ejemplo A: El Sumador Unario (+1)

Objetivo: Tienes un número unario (ej. "11" que representa el número 2). La máquina debe leer la cadena, viajar hacia la derecha hasta encontrar un hueco vacío '_', escribir un '1' (sumando así +1), y detenerse en el estado de aceptación.

public class MTSumador {
    public static void main(String[] args) {
        // 1. Preparamos la cinta
        char[] cinta = new char[20];
        java.util.Arrays.fill(cinta, '_');
        
        // Simulamos la entrada "11" en el centro
        cinta[5] = '1'; 
        cinta[6] = '1';
        
        int cabezal = 5;
        int estado = 0;
        
        // 2. Máquina de Estados (Bucle)
        while(estado != 99) {
            char leido = cinta[cabezal];
            
            if (estado == 0) {
                if (leido == '1') {
                    // Solo paso por encima, no borro
                    cinta[cabezal] = '1'; 
                    cabezal++; // Muevo a R (Derecha)
                    estado = 0;  // Me mantengo en q0 buscando el fin
                } 
                else if (leido == '_') {
                    // ¡Encontré un hueco! Añado el "+1"
                    cinta[cabezal] = '1'; 
                    estado = 99; // Estado de Aceptación (Fin)
                }
            }
        }
        
        // Resultado: Imprime la cinta
        System.out.println(String.valueOf(cinta));
        // Salida esperada: _____111____________
    }
}
¿Cómo lo procesa la computadora?
  • El cabezal inicia en el índice 5, donde hay un '1'.
  • El programa entra al while en el estado 0. Lee un '1'. La regla le dice: "Deja el 1 como está, avanza a la derecha (índice 6) y sigue en estado 0".
  • En la siguiente vuelta (vuelta 2), el cabezal está en el índice 6. Vuelve a leer '1'. Hace lo mismo: avanza a la derecha (índice 7).
  • En la vuelta 3, el cabezal está en el índice 7. ¡Ahora lee un '_'!
  • La regla para '_' en el estado 0 se activa: "Escribe un '1' aquí mismo y cambia el estado a 99".
  • El ciclo while se rompe porque estado ahora es 99. La máquina ha terminado y hemos convertido "11" en "111".

Ejemplo B: El Complemento Binario (Filtro Inteligente)

Objetivo: Tienes una cadena binaria (ej. "1010"). La MT debe leerla de izquierda a derecha, invirtiendo cada bit (los 1 se hacen 0 y los 0 se hacen 1). Al terminar la cadena (cuando lea '_'), se detiene.

public class MTComplemento {
    public static void main(String[] args) {
        // 1. Cinta con la cadena "1010"
        char[] cinta = {'_', '1', '0', '1', '0', '_'};
        
        int cabezal = 1; // Apunta al primer '1'
        int estado = 0;
        
        // 2. Máquina de Estados (Bucle)
        while(estado != 99) {
            char leido = cinta[cabezal];
            
            if (estado == 0) {
                if (leido == '0') {
                    cinta[cabezal] = '1'; // Reescribe a 1
                    cabezal++;           // Sigue a la derecha
                    estado = 0;
                } 
                else if (leido == '1') {
                    cinta[cabezal] = '0'; // Reescribe a 0
                    cabezal++;           // Sigue a la derecha
                    estado = 0;
                }
                else if (leido == '_') {
                    // Si lee blanco, ya no hay más cadena
                    estado = 99; // Detener máquina
                }
            }
        }
        
        // Imprime: _0101_
        System.out.println(String.valueOf(cinta)); 
    }
}
El Poder de la Transformación *In Situ*

A diferencia de un arreglo tradicional en Java donde leeríamos y guardaríamos el resultado en otro String, la Máquina de Turing hace el trabajo en la misma cinta (memoria dinámica).

  • El bloque if (leido == '0') y else if (leido == '1') mantienen el estado en 0, lo que significa que la máquina repite la misma lógica una y otra vez para cada carácter de la palabra.
  • El cabezal avanza implacablemente a la derecha con cabezal++.
  • La condición de salida es elegantísima: Cuando la palabra física se acaba y el cabezal pisa un "hueco" ('_'), manda la señal 99 y apaga la máquina.

Ejemplo C: Máquina de Estados Estricta (Bloqueo de Cajero ATM)

Objetivo: Simular el sistema de seguridad de un cajero. La cinta contiene un historial de intentos de PIN ('C' = Correcto, 'E' = Error). El cajero tolerará hasta 2 errores. Al 3er error consecutivo, la máquina entra en estado de Bloqueo, escribe una marca 'B' en la cinta y retiene la tarjeta.

public class MTCajeroSeguridad {
    public static void main(String[] args) {
        // Historial: 2 errores, 1 acierto, 3 errores seguidos
        char[] cinta = {'_', 'E', 'E', 'C', 'E', 'E', 'E', '_'};
        
        int cabezal = 1;
        int estado = 0; // 0: Normal, 1: Un Error, 2: Dos Errores, 3: Bloqueado
        
        // Bucle de Transiciones (Motor Switch)
        while (estado != 99 && estado != -1) {
            char leido = cinta[cabezal];
            
            switch (estado) {
                case 0: // ESTADO SEGURO
                    if (leido == 'C') cabezal++; // Todo bien
                    else if (leido == 'E') { estado = 1; cabezal++; } // 1er Error
                    else if (leido == '_') estado = 99; // Terminó sin bloqueo
                    break;
                    
                case 1: // UN ERROR RECIENTE
                    if (leido == 'C') { estado = 0; cabezal++; } // Se recupera a 0
                    else if (leido == 'E') { estado = 2; cabezal++; } // 2do Error
                    else if (leido == '_') estado = 99;
                    break;

                case 2: // DOS ERRORES (Alerta)
                    if (leido == 'C') { estado = 0; cabezal++; } // Salvado
                    else if (leido == 'E') {
                        estado = 3; // 3er ERROR CONSECUTIVO
                        cinta[cabezal] = 'B'; // Marca de Bloqueo en la cinta
                        cabezal++;
                    }
                    else if (leido == '_') estado = 99;
                    break;

                case 3: // ESTADO POZO (Tarjeta Retenida)
                    // Ignoramos todo hasta terminar el registro
                    if (leido == '_') estado = -1; // Máquina Rechaza
                    else cabezal++;
                    break;
            }
        }
        
        // Imprime: _EEC E E B _ (El último intento fatal se marca)
        System.out.println(String.valueOf(cinta)); 
    }
}
Transiciones Clásicas (\(\delta\))

Usar un bloque switch(estado) es la forma más pura y profesional de representar la Función de Transición (\(\delta\)) de una Máquina de Turing en Java.

  • El switch controla en qué Estado de la máquina (Q) nos encontramos actualmente. Es la memoria del sistema.
  • Si ingresamos una 'C' (Correcto) estando en el Estado 1 o 2, la máquina se "resetea" regresando al Estado 0.
  • El Estado 3 es un Estado Pozo. Una vez que el sistema entra ahí (por 3 errores), ninguna combinación de caracteres lo dejará salir. Finalmente, detendrá el motor con un Rechazo Absoluto (-1).

Ejemplo D: Transcriptor de ADN a ARN (Bioinformática)

Objetivo: Las Máquinas de Turing procesan letras, no solo números. En biología, para transcribir ADN a ARN, la Timina (T) se reemplaza por Uracilo (U). Nuestra MT leerá la cinta biológica, reemplazará cada 'T' que encuentre por 'U' dejando intactas las A, C y G, y se detendrá al final.

public class MT_Bioinformatica {
    public static void main(String[] args) {
        // 1. Cinta biológica (ADN: ATCGT)
        char[] cinta = {'_', 'A', 'T', 'C', 'G', 'T', '_'};
        
        int cabezal = 1; // Apunta a la primera 'A'
        int estado = 0;
        
        // 2. Máquina de Estados (Bucle)
        while(estado != 99 && estado != -1) {
            char leido = cinta[cabezal];
            
            switch(estado) {
                case 0: // Estado de Lectura/Traducción
                    if (leido == 'A' || leido == 'C' || leido == 'G') {
                        // Bases válidas, avanzamos sin cambiar nada
                        cabezal++; 
                    } 
                    else if (leido == 'T') {
                        cinta[cabezal] = 'U'; // Transcribimos Timina a Uracilo
                        cabezal++;           // Seguimos adelante
                    }
                    else if (leido == '_') {
                        // Fin de la secuencia genética
                        estado = 99; // Aceptado
                    }
                    else {
                        // Símbolo extraño (Ej. 'X' o 'Z') rompe el ADN
                        estado = -1; // Rechazado
                    }
                    break;
            }
        }
        
        // Imprime la transcripción resultante (ARN): _AUCGU_
        System.out.println(String.valueOf(cinta)); 
    }
}
Las MT procesan Textos Reales

Las Máquinas de Turing son modelos universales de computación. Cualquier operación de procesamiento de texto estructurado puede ser evaluada aquí.

  • Aquí vemos cómo el "Alfabeto" de entrada de la máquina es \(\Sigma = \{A, C, G, T\}\) y no los clásicos ceros y unos.
  • Se introduce un estado de Rechazo (-1). Si la máquina lee un carácter fuera del alfabeto biológico (como una 'X'), aborta la ejecución para prevenir datos corruptos.

Ejemplo E: Cifrado Básico (Procesamiento de Texto)

Objetivo: Diseñar una Máquina de Turing que encripte un mensaje desplazando el valor de cada letra una posición hacia adelante en el abecedario (A se vuelve B, B se vuelve C). Este es el principio básico de la criptografía antigua (Cifrado César ROT-1).

public class MT_Encriptador {
    public static void main(String[] args) {
        // 1. Mensaje en la cinta (HOLZ)
        char[] cinta = {'_', 'H', 'O', 'L', 'Z', '_'};
        
        int cabezal = 1;
        int estado = 0;
        
        // 2. Máquina de Estados
        while(estado != 99) {
            char leido = cinta[cabezal];
            
            switch(estado) {
                case 0:
                    // Si es una letra de la A a la Y
                    if (leido >= 'A' && leido < 'Z') {
                        // Reescribe la cinta sumando +1 al valor ASCII
                        cinta[cabezal] = (char)(leido + 1);
                        cabezal++;
                    } 
                    // Caso especial: Si es la Z, la rotamos hacia la A
                    else if (leido == 'Z') {
                        cinta[cabezal] = 'A';
                        cabezal++;
                    }
                    // Condición de parada
                    else if (leido == '_') {
                        estado = 99; // Mensaje encriptado con éxito
                    }
                    break;
            }
        }
        
        // Imprime: _IPMA_
        System.out.println(String.valueOf(cinta)); 
    }
}
Aprovechando el código ASCII

Para no tener que programar 26 estados `if` distintos (uno para cada letra), usamos las propiedades numéricas subyacentes de los caracteres en Java.

  • La operación (char)(leido + 1) toma el valor numérico de la letra (ej. H = 72) y le suma 1 (73 = I), reescribiéndolo de forma eficiente en la cinta.
  • Al llegar al espacio en blanco '_', la MT da por concluida la operación criptográfica y se detiene automáticamente.

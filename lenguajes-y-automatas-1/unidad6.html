Unidad 6: Análisis Sintáctico (Parser)

Duración: 18 Horas (18 Horas) • Nivel Avanzado • Docente: Cruz Enrique García

El Análisis Sintáctico (o parsing) es el corazón de la etapa de análisis del compilador. Toma la secuencia de tokens producida por el analizador léxico y verifica si dicha secuencia satisface las reglas estructurales de la gramática del lenguaje, construyendo una representación jerárquica denominada árbol de sintaxis (Parse Tree / AST).

Competencia Específica

Construir un analizador sintáctico a partir de un lenguaje de programación o un generador automático (YACC, CUP, Bison, ANTLR) para el reconocimiento y validación formal de gramáticas libres de contexto, cálculo de conjuntos predictivos y manejo de errores.

6.1 Gramáticas Libres de Contexto (GLC)

Una Gramática Libre de Contexto es una estructura formal matemática definida formalmente como una 4-tupla:

$$G = (V, \Sigma, R, S)$$
  • \(V\) (No terminales): Conjunto finito de variables sintácticas que definen subestructuras del lenguaje (ej. \(E, T, F, \text{Sentencia}\)).
  • \(\Sigma\) (Terminales): Alfabeto de símbolos básicos provistos como tokens por el analizador léxico (ej. \(+, *, \mathbf{id}, (, )\)).
  • \(R\) (Reglas de producción): Conjunto de producciones de la forma \(A \to \alpha\), donde \(A \in V\) y \(\alpha \in (V \cup \Sigma)^*\).
  • \(S\) (Símbolo inicial): Variable distinguida \(S \in V\) que representa la construcción máxima (ej. Programa).
Gramática Estándar de Expresiones Aritméticas (Notación BNF) 
E -> E + T  |  T
T -> T * F  |  F
F -> ( E )  |  id  |  num

6.2 Árboles de Derivación (Parse Trees)

Un árbol de derivación muestra de forma gráfica cómo se deriva una cadena a partir del símbolo inicial:

Árbol Sintáctico para: id + id * id
        E
       /|\
      E + T
      |  /|\
      T T * F
      | |   |
      F F   id
      | |
     id id

Nótese cómo la multiplicación (*) queda en un nivel más profundo, respetando la precedencia de operadores.

6.3 Formas Normales de Chomsky y Greibach

Para el análisis teórico y algoritmos de parsing dinámico (como CYK), las gramáticas se normalizan:

Forma Normal de Chomsky (FNC)

Toda producción tiene únicamente una de dos formas:

\(A \to BC\)   ó   \(A \to a\)

Forma Normal de Greibach (FNG)

Toda producción inicia con un símbolo terminal:

\(A \to a \alpha\)   con \(\alpha \in V^*\)

6.4 Diagramas de Sintaxis (Diagramas de Ferrocarril)

Representación gráfica visual de las reglas gramaticales utilizada históricamente en especificaciones de lenguajes como Pascal y JSON. Los no terminales se representan como rectángulos y los terminales como círculos/óvalos conectados por trayectorias direccionadas.

Diagrama de Ferrocarril: Sentencia IF
──► [ if ] ──► ( Condición ) ──► [ Sentencia ] ──┬──────────────────► └──► [ else ] ──► [ Sentencia ] ──┘

6.5 Eliminación de Ambigüedad y Recursividad Izquierda

Una gramática es ambigua si genera más de un árbol de derivación para una misma cadena. Los analizadores descendentes LL(1) no admiten gramáticas con recursividad por la izquierda ni factores comunes.

Fórmula de Eliminación de Recursividad Izquierda Directa

Dada una regla con recursividad izquierda:

\(A \to A \alpha \mid \beta\)   (donde \(\beta\) no empieza con \(A\))

Se transforma de forma equivalente en:

\(A \to \beta A'\)
\(A' \to \alpha A' \mid \varepsilon\)

6.6 Cálculo de Conjuntos FIRST (Primeros) y FOLLOW (Siguientes)

Los conjuntos predictivos FIRST y FOLLOW permiten a un parser LL(1) decidir qué producción aplicar sin retroceso (*backtracking*).

Definición de FIRST(\(\alpha\))

Conjunto de terminales que pueden iniciar las cadenas derivadas de \(\alpha\). Si \(\alpha \Rightarrow^* \varepsilon\), entonces \(\varepsilon \in \text{FIRST}(\alpha)\).

Definición de FOLLOW(\(A\))

Conjunto de terminales que pueden aparecer inmediatamente a la derecha de \(A\) en alguna derivación. El símbolo de fin de archivo (\(\$\)) siempre pertenece a \(\text{FOLLOW}(S)\).

No Terminal FIRST FOLLOW
E { id, ( } { $, ) }
E' { +, ε } { $, ) }
T { id, ( } { +, $, ) }
T' { *, ε } { +, $, ) }
F { id, ( } { *, +, $, ) }

6.7 Tipos de Analizadores: Top-Down vs Bottom-Up

Descendentes (Top-Down)

Construyen el árbol desde la raíz hacia las hojas:

  • Descenso Recursivo
  • LL(1) Predictivo No Recursivo (Tabla)

Ascendentes (Bottom-Up)

Reducen desde las hojas hacia la raíz (Shift-Reduce):

  • LR(0) / SLR(1)
  • LALR(1) (Yacc, Bison, CUP)
  • LR(1) Canónico

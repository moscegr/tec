2.1

Formalización del Análisis Léxico y Modelos Regulares

1. Explicación Teórica y Conceptual

El Analizador Léxico (o Scanner) es el primer módulo del compilador. Su función principal es leer el flujo secuencial de caracteres del archivo fuente y agruparlos en unidades con significado léxico llamadas tokens. El analizador sintáctico solicita tokens bajo demanda mediante llamadas a la función nextToken().

Para especificar formalmente los componentes léxicos se emplean tres formalismos isomorfos (intercambiables):

  • • Gramáticas Lineales (por la derecha o izquierda): Conjunto de reglas de reescritura \(A \to x B \mid x\) con \(x \in T\).
  • • Expresiones Regulares (ER): Fórmulas algebraicas sobre terminales con operadores de concatenación (\(\cdot\)), unión (\(\mid\)) y cerraduras (\(*, +\)).
  • • Autómatas Finitos Deterministas (AFD) y No Deterministas (AFND): Grafos de estados y transiciones donde se consumen caracteres para alcanzar estados de aceptación.
2. Glosario de Términos y Definiciones
• Token: Unidad léxica abstracta indivisible (ej. <ID, "contador">, <PR_WHILE, "while">).
• Lexema: Cadena exacta de caracteres del código fuente que concuerda con un patrón léxico.
• Patrón Léxico: Expresión regular abstracta que describe a la familia de lexemas del token.
• Cadena Propia vs No Propia: Propia si es idéntica al patrón (palabras reservadas como while); no propia si es variable (identificadores o números).

4. Ejercicio Guiado: Conversión de Gramática Lineal a Expresión Regular y AFD

Problema: Dada la gramática lineal por la derecha \(G = (\{l, d\}, \{A, B\}, A, P)\) con producciones \(A \to l B, B \to l B \mid d B \mid \varepsilon\):

1. Expresión Regular equivalente: \(L(G) = l (l \mid d)^*\) (Identificadores en programación).

2. Autómata Finito: Estado inicial 0 lee letra \(l\) y pasa a estado 1. Estado 1 tiene lazo reflexivo con letra o dígito y transición otro (\(*\)) hacia el estado final de aceptación 2 emitiendo el token <ID>.

2.2

Estrategias de Implementación de Analizadores Léxicos

1. Explicación Teórica

Existen tres paradigmas de codificación para analizadores léxicos:

  1. Implementación Basada en Casos (Hardcoded): Emplea bucles while y sentencias switch (estado) anidadas con switch (caracter). Es eficiente pero difícil de mantener.
  2. Implementación Dirigida por Tablas: Se almacena la matriz de transición \(M[Q, T] \to Q\) y un bucle genérico itera sobre los caracteres.
  3. Implementación Guiada por Herramientas (JFlex): Se definen reglas patrón - acción en un archivo .flex y JFlex compila automáticamente un AFD determinista optimizado en Java.
Reglas de Resolución de Ambigüedad en JFlex:

1. Preferencia al token más largo (Longest Match): Entre > y >=, la cadena >= se reconoce como un solo operador de comparación.
2. Preferencia de orden de aparición: Las palabras reservadas (while, if) se declaran antes que el patrón general de identificadores {LETRA}({LETRA}|{DIGITO})*.

3. Comparativa: Hardcoded Switch vs JFlex Declarativo
// 1. Hardcoded Switch-Case en Java
while (!fin) {
  switch(estado) {
    case 0: if (isLetra(c)) { estado=1; lex+=c; } break;
    case 1: if (isLetra(c)||isDigito(c)) lex+=c; else fin=true; break;
  }
}
// 2. Regla JFlex en Scanner.flex
LETRA = [a-zA-Z_]
DIGITO = [0-9]
ID = {LETRA}({LETRA}|{DIGITO})*

<YYINITIAL> {ID} { return new Token("ID", yytext(), yyline, yychar); }

2.3

Anatomía y Directivas de un Archivo JFlex (`.flex`)

1. Explicación de las 3 Secciones de JFlex

Un archivo de especificación léxica de JFlex se divide estrictamente en tres secciones separadas por el delimitador %%:

Sección 1: Código de Usuario (Imports y Paquetes)
Se ubica antes del primer %%. Todo el código Java escrito aquí se copia verbatim al inicio de la clase generada Scanner.java (ej. package compiler.lexical; import java.util.*;).
Sección 2: Opciones, Directivas y Macros
Entre el primer y segundo %%. Se configuran directivas como %class Scanner, %public, %unicode, %line, %column, %type Token y se definen macros de expresiones regulares.
Sección 3: Reglas Léxicas (Patrón ➔ Acción)
Después del segundo %%. Cada regla asocia un patrón de expresión regular con un bloque de código Java ejecutable: patron { codigo_java; }.
3. Código Fuente del Archivo Lexer.flex 
/* ======================================================
   SECCIÓN 1: Código de Usuario
   ====================================================== */
package mi.compilador;
import java.io.*;

%%
/* ======================================================
   SECCIÓN 2: Opciones y Directivas de JFlex
   ====================================================== */
%class Lexer
%public
%unicode
%line
%column
%type Token

/* Declaración de variables y métodos de apoyo */
%{
    private Token crearToken(String tipo) {
        return new Token(tipo, yytext(), yyline + 1, yycolumn + 1);
    }
%}

/* Definición de Macros de Expresiones Regulares */
LETRA        = [a-zA-Z_]
DIGITO       = [0-9]
ESPACIO      = [ \t\r\n]+
IDENTIFICADOR= {LETRA}({LETRA}|{DIGITO})*
NUM_ENTERO   = {DIGITO}+
NUM_DECIMAL  = {DIGITO}+ \. {DIGITO}+

/* Declaración de Estado Léxico para Comentarios Multilínea */
%state COMENTARIO

%%
/* ======================================================
   SECCIÓN 3: Reglas Patrón - Acción
   ====================================================== */
<YYINITIAL> {
    /* Palabras Reservadas (Declaradas primero) */
    "if"          { return crearToken("PR_IF"); }
    "else"        { return crearToken("PR_ELSE"); }
    "while"       { return crearToken("PR_WHILE"); }
    "int"         { return crearToken("TIPO_INT"); }
    "float"       { return crearToken("TIPO_FLOAT"); }
    "return"      { return crearToken("PR_RETURN"); }

    /* Operadores Aritméticos y Asignación */
    "+"           { return crearToken("OP_SUMA"); }
    "-"           { return crearToken("OP_RESTA"); }
    "*"           { return crearToken("OP_MULT"); }
    "/"           { return crearToken("OP_DIV"); }
    "="           { return crearToken("OP_ASIGN"); }

    /* Operadores Relacionales */
    "=="          { return crearToken("OP_IGUAL"); }
    "!="          { return crearToken("OP_DIFERENTE"); }
    "<="          { return crearToken("OP_MENOR_IGUAL"); }
    ">="          { return crearToken("OP_MAYOR_IGUAL"); }
    "<"           { return crearToken("OP_MENOR"); }
    ">"           { return crearToken("OP_MAYOR"); }

    /* Delimitadores */
    "("           { return crearToken("PARENTESIS_IZQ"); }
    ")"           { return crearToken("PARENTESIS_DER"); }
    "{"           { return crearToken("LLAVE_IZQ"); }
    "}"           { return crearToken("LLAVE_DER"); }
    ";"           { return crearToken("PUNTO_Y_COMA"); }
    ","           { return crearToken("COMA"); }

    /* Literales y Variables */
    {NUM_DECIMAL}   { return crearToken("CONST_FLOAT"); }
    {NUM_ENTERO}    { return crearToken("CONST_INT"); }
    {IDENTIFICADOR} { return crearToken("ID"); }

    /* Ignorar Espacios en Blanco */
    {ESPACIO}       { /* Ignorar */ }

    /* Inicio de Comentario Multilínea */
    "/*"            { yybegin(COMENTARIO); }
    "//".*          { /* Ignorar comentario de una línea */ }

    /* Captura de Errores Léxicos */
    .               { return crearToken("ERROR_LEXICO"); }
}

<COMENTARIO> {
    "*/"            { yybegin(YYINITIAL); }
    [^*\n]+         { /* Ignorar contenido */ }
    "*"             { /* Ignorar */ }
    \n              { /* Ignorar saltos de línea */ }
}
4. Clase Token.java de Soporte 
package mi.compilador;

public class Token {
    private String tipo;
    private String lexema;
    private int linea;
    private int columna;

    public Token(String tipo, String lexema, int linea, int columna) {
        this.tipo = tipo;
        this.lexema = lexema;
        this.linea = linea;
        this.columna = columna;
    }

    @Override
    public String toString() {
        return String.format("[Línea %02d, Col %02d] %-16s -> '%s'", linea, columna, tipo, lexema);
    }

    // Getters
    public String getTipo() { return tipo; }
    public String getLexema() { return lexema; }
    public int getLinea() { return linea; }
    public int getColumna() { return columna; }
}
2.4

Compilación y Ejecución en Consola (VS Code + javac + java)

1. Flujo de Trabajo en Terminal / PowerShell

Para ejecutar JFlex desde la consola de comandos (en Windows PowerShell o terminal de Linux/Mac dentro de Visual Studio Code), se utiliza la herramienta jflex.jar y el compilador estándar javac:

# 1. Generar la clase Lexer.java a partir de Lexer.flex

java -jar lib/jflex-full-1.9.1.jar src/mi/compilador/Lexer.flex

# 2. Compilar todas las clases Java del paquete

javac -d bin -cp src src/mi/compilador/*.java

# 3. Ejecutar el analizador pasándole un archivo fuente de prueba

java -cp bin mi.compilador.Principal pruebas/programa.src

3. Clase Principal.java para Lectura de Archivo en Consola 
package mi.compilador;
import java.io.*;

public class Principal {
    public static void main(String[] args) {
        if (args.length == 0) {
            System.out.println("Uso: java mi.compilador.Principal ");
            return;
        }

        File archivo = new File(args[0]);
        if (!archivo.exists()) {
            System.err.println("Error: El archivo '" + args[0] + "' no existe.");
            return;
        }

        try (FileReader reader = new FileReader(archivo);
             BufferedReader br = new BufferedReader(reader)) {

            System.out.println("=================================================");
            System.out.println("   INICIANDO ANÁLISIS LÉXICO CON JFLEX (CONSOLA)");
            System.out.println("   Archivo: " + archivo.getName());
            System.out.println("=================================================");

            Lexer lexer = new Lexer(br);
            Token token;
            int totalTokens = 0;
            int totalErrores = 0;

            while ((token = lexer.yylex()) != null) {
                totalTokens++;
                if ("ERROR_LEXICO".equals(token.getTipo())) {
                    totalErrores++;
                    System.err.printf("[ERROR LÉXICO] Carácter desconocido en Línea %d, Col %d: '%s'%n",
                            token.getLinea(), token.getColumna(), token.getLexema());
                } else {
                    System.out.println(token);
                }
            }

            System.out.println("=================================================");
            System.out.printf("Análisis finalizado: %d tokens reconocidos, %d errores léxicos.%n",
                    totalTokens, totalErrores);

        } catch (IOException e) {
            System.err.println("Excepción de E/S: " + e.getMessage());
        }
    }
}

Proyecto Completo en Apache NetBeans con GUI (`javax.swing`)

1. Arquitectura de la Aplicación Visual Swing

En esta fase, integramos el escáner generado por JFlex dentro de una aplicación de escritorio profesional en Apache NetBeans utilizando la librería estándar javax.swing y java.awt:

  • • JFileChooser: Diálogo para buscar y seleccionar archivos de texto con código fuente (.txt, .c, .pas).
  • • JTextArea con números de línea: Editor de texto donde el alumno puede escribir código directamente o ver el archivo cargado.
  • • JTable con DefaultTableModel: Tabla interactiva donde se listan los tokens encontrados con columnas: Línea, Columna, Tipo de Token, Lexema.
  • • JOptionPane: Diálogos de advertencia y mensajes de éxito al concluir el análisis léxico.
3. Código Completo del Formulario Visual: VentanaCompilador.java 
package mi.compilador.gui;

import javax.swing.*;
import javax.swing.table.DefaultTableModel;
import java.awt.*;
import java.awt.event.*;
import java.io.*;
import mi.compilador.Lexer;
import mi.compilador.Token;

public class VentanaCompilador extends JFrame {

    private JTextArea txtCodigo;
    private JTable tblTokens;
    private DefaultTableModel modeloTabla;
    private JButton btnAbrir, btnAnalizar, btnLimpiar;
    private JLabel lblEstado;

    public VentanaCompilador() {
        super("Compilador Didáctico • Analizador Léxico con JFlex - IT Chilpancingo");
        initComponents();
    }

    private void initComponents() {
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(950, 650);
        setLocationRelativeTo(null);
        setLayout(new BorderLayout(8, 8));

        // Panel Superior de Herramientas (Botones)
        JPanel pnlHerramientas = new JPanel(new FlowLayout(FlowLayout.LEFT, 10, 8));
        btnAbrir = new JButton("Abrir Archivo (.txt / .src)", new ImageIcon());
        btnAnalizar = new JButton("Analizar Léxico con JFlex");
        btnLimpiar = new JButton("Limpiar Tablas");

        btnAbrir.setBackground(new Color(241, 245, 249));
        btnAnalizar.setBackground(new Color(79, 70, 229));
        btnAnalizar.setForeground(Color.WHITE);
        btnAnalizar.setFont(new Font("SansSerif", Font.BOLD, 12));

        pnlHerramientas.add(btnAbrir);
        pnlHerramientas.add(btnAnalizar);
        pnlHerramientas.add(btnLimpiar);
        add(pnlHerramientas, BorderLayout.NORTH);

        // Panel Central Dividido: Editor a la izquierda, Tabla de Tokens a la derecha
        JSplitPane splitPane = new JSplitPane(JSplitPane.HORIZONTAL_SPLIT);
        splitPane.setResizeWeight(0.5);

        // Editor de Código
        txtCodigo = new JTextArea();
        txtCodigo.setFont(new Font("Monospaced", Font.PLAIN, 14));
        txtCodigo.setText("// Escribe o abre un archivo para analizar con JFlex\nint total = 100;\nif (total >= 50) {\n    float promedio = 8.5;\n}\n");
        JScrollPane scrollCodigo = new JScrollPane(txtCodigo);
        scrollCodigo.setBorder(BorderFactory.createTitledBorder("Editor de Código Fuente"));
        splitPane.setLeftComponent(scrollCodigo);

        // Tabla de Tokens
        String[] columnas = {"Línea", "Columna", "Componente Léxico (Token)", "Lexema"};
        modeloTabla = new DefaultTableModel(columnas, 0);
        tblTokens = new JTable(modeloTabla);
        tblTokens.setFont(new Font("SansSerif", Font.PLAIN, 12));
        tblTokens.setRowHeight(22);
        JScrollPane scrollTabla = new JScrollPane(tblTokens);
        scrollTabla.setBorder(BorderFactory.createTitledBorder("Tokens Reconocidos (Tabla de Símbolos)"));
        splitPane.setRightComponent(scrollTabla);

        add(splitPane, BorderLayout.CENTER);

        // Barra de Estado Inferior
        lblEstado = new JLabel(" Listo para analizar código fuente.");
        lblEstado.setBorder(BorderFactory.createEtchedBorder());
        add(lblEstado, BorderLayout.SOUTH);

        // Eventos de los Botones
        btnAbrir.addActionListener(e -> abrirArchivo());
        btnAnalizar.addActionListener(e -> ejecutarAnalisisLexico());
        btnLimpiar.addActionListener(e -> {
            txtCodigo.setText("");
            modeloTabla.setRowCount(0);
            lblEstado.setText(" Tablas limpias.");
        });
    }

    private void abrirArchivo() {
        JFileChooser chooser = new JFileChooser();
        int opc = chooser.showOpenDialog(this);
        if (opc == JFileChooser.APPROVE_OPTION) {
            File f = chooser.getSelectedFile();
            try (BufferedReader br = new BufferedReader(new FileReader(f))) {
                txtCodigo.read(br, null);
                lblEstado.setText(" Archivo cargado: " + f.getAbsolutePath());
            } catch (IOException ex) {
                JOptionPane.showMessageDialog(this, "Error al leer archivo: " + ex.getMessage(),
                        "Error E/S", JOptionPane.ERROR_MESSAGE);
            }
        }
    }

    private void ejecutarAnalisisLexico() {
        String codigo = txtCodigo.getText();
        if (codigo.trim().isEmpty()) {
            JOptionPane.showMessageDialog(this, "El editor de código está vacío.",
                    "Aviso", JOptionPane.WARNING_MESSAGE);
            return;
        }

        modeloTabla.setRowCount(0); // Limpiar tabla previa
        Reader reader = new StringReader(codigo);
        Lexer lexer = new Lexer(reader);
        Token token;
        int count = 0;
        int errores = 0;

        try {
            while ((token = lexer.yylex()) != null) {
                count++;
                if ("ERROR_LEXICO".equals(token.getTipo())) {
                    errores++;
                }
                modeloTabla.addRow(new Object[]{
                    token.getLinea(),
                    token.getColumna(),
                    token.getTipo(),
                    token.getLexema()
                });
            }

            lblEstado.setText(String.format(" Análisis finalizado: %d tokens procesados (%d errores).", count, errores));
            if (errores > 0) {
                JOptionPane.showMessageDialog(this,
                    "Se encontraron " + errores + " errores léxicos en el código fuente.",
                    "Reporte Léxico", JOptionPane.WARNING_MESSAGE);
            } else {
                JOptionPane.showMessageDialog(this,
                    "¡Análisis Léxico exitoso! " + count + " tokens identificados sin errores.",
                    "Éxito", JOptionPane.INFORMATION_MESSAGE);
            }

        } catch (IOException ex) {
            JOptionPane.showMessageDialog(this, "Error durante el escaneo: " + ex.getMessage(),
                    "Error", JOptionPane.ERROR_MESSAGE);
        }
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            new VentanaCompilador().setVisible(true);
        });
    }
}

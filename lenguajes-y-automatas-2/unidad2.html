Unidad 2: Generación de Código Intermedio

Duración: 20 Horas (Semanas 5-8) • Nivel Intermedio • Docente: Cruz Enrique García

El Código Intermedio es una representación del programa fuente en un lenguaje abstracto de bajo nivel independiente de la arquitectura física de la máquina destino. Su objetivo principal es desacoplar el análisis de la síntesis: permite optimizar el código una sola vez y reutilizar el mismo front-end para generar código máquina hacia múltiples plataformas (x86, ARM, RISC-V, MIPS o JVM).

Competencia Específica

Diseñar y programar las reglas y esquemas de traducción para transformar el árbol sintáctico en representaciones intermedias (Código de Tres Direcciones, Cuádruplos, Triplos y Código P), implementando el control de flujo con backpatching y el cálculo de desplazamientos en estructuras de datos.

2.1 Notaciones: Infija, Prefija y Postfija

La posición del operador respecto a sus operandos determina la notación. En compiladores, las notaciones sin paréntesis (Polaca y Polaca Inversa) son ideales para la evaluación mediante máquinas de pila.

Notación Infija

Operador entre los operandos. Requiere reglas de precedencia y paréntesis.

(a + b) * (c - d)
Notación Prefija (Polaca)

Operador antes de sus operandos. No requiere paréntesis.

* + a b - c d
Notación Postfija (Polaca Inversa)

Operador después de sus operandos. Base de la JVM y calculadoras RPN.

a b + c d - *

2.2 Representaciones: Triplos, Cuádruplos y TAC

Las tres estructuras clásicas para representar código intermedio lineal son:

1. Código de Tres Direcciones (TAC / 3AC)

Secuencia lineal de instrucciones con como máximo un operador y a lo sumo 3 direcciones de memoria (2 operandos fuente y 1 destino temporal):

t1 = a + b
t2 = c - d
t3 = t1 * t2
Estructura Campos Ejemplo para: x = a + b * c Ventaja Principal
Cuádruplo (op, arg1, arg2, res) (*, b, c, t1)
(+, a, t1, x)		 Fácil de reordenar en optimizaciones.
Triplo (op, arg1, arg2) (0) (*, b, c)
(1) (+, a, (0))		 Ahorra memoria al no nombrar temporales.

2.3 Esquemas de Generación (Control de Flujo y Arreglos)

Traducción de Sentencias de Control (`if-else`, `while`)

Para estructuras de control condicionales se generan etiquetas de salto (*labels*) y saltos condicionales (`if_false x goto L1`).

// Código Alto Nivel: if (a < b) {
    x = 10;
} else {
    x = 20;
}
// Código TAC Generado:     if_false (a < b) goto L1
    x = 10
    goto L2
L1: x = 20
L2: // Continuación

Fórmula de Desplazamiento para Arreglos 2D (\(A[i][j]\))

En almacenamiento por filas (*Row-Major Order*):

$$\text{Dirección}(A[i][j]) = \text{Base}(A) + \left( i \times N_{\text{cols}} + j \right) \times \text{TamElemento}$$

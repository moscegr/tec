2.1

¿Qué es el Análisis Léxico? Patrones, Lexemas y Expresiones

1. Explicación Teórica y Conceptual

El análisis léxico consiste en identificar dentro de un flujo de texto aquellas cadenas que se ajustan (encajan) a un determinado patrón lingüístico.

"Aunque la inauguración de la Feria Internacional del Turismo y el Ocio (FITO'04) se pensaba realizar el 25/06/2004, la falta de 250.000.000 euros ha determinado posponer dicho acontecimiento hasta el 25 de octubre en el que se espera recibir una subvención de 75 millones de euros procedentes de la UE y de 150 de las arcas del estado."

SIGLAS: FITO'04, UE
FECHAS: 25/06/2004, 25 de octubre
CANTIDADES: 250.000.000 euros, 150

Las Expresiones Regulares (ExpReg) son el medio estándar más potente para describir estos patrones léxicos mediante combinaciones de caracteres UNICODE, rangos [a-z], comodines ., opciones ?, cerraduras * y +.

2. Glosario de Operadores y Metacaracteres Básicos
• Unión (\(\alpha \mid \beta\)): Cadenas que encajen en \(\alpha\) o en \(\beta\) (ej. a|e|i|o|u).
• Concatenación (\(\alpha \beta\)): Cadena \(\alpha\) seguida inmediatamente de \(\beta\).
• Cierre Estrella (\(\alpha^*\)): Cero o más repeticiones de \(\alpha\).
• Cierre Positivo (\(\alpha^+\)): Una o más repeticiones (ej. be+ ➔ be, bee, beee...).
• Opcionalidad (\(\alpha?\)): Una o ninguna aparición (0 ó 1).
• Comodín (.): Cualquier carácter individual excepto el salto de línea.
• Conjunto ([aeiou]): Cualquier vocal. [^0-9]: Cualquier carácter no numérico.
• Secuencias de escape: \n (salto línea), \t (tabulador), \r (retorno carro).

Variables de Entorno (PATH) y Comandos Sencillos (JFlex & CUP)

1. Configuración de Variables de Entorno en Windows / Linux

Para ejecutar jflex y cup desde cualquier terminal o en Visual Studio Code sin escribir rutas largas de archivos .jar, agregamos su carpeta bin a la variable de entorno Path del sistema.

// Paso 1: Configurar variables en Windows (PowerShell como Administrador o GUI)

[System.Environment]::SetEnvironmentVariable("JFLEX_HOME", "C:\compiladores\jflex-1.9.1", "User")

[System.Environment]::SetEnvironmentVariable("CUP_HOME", "C:\compiladores\java-cup-bin-11b", "User")

// Paso 2: Añadir al PATH de usuario

$viejoPath = [System.Environment]::GetEnvironmentVariable("Path", "User")

[System.Environment]::SetEnvironmentVariable("Path", "$viejoPath;C:\compiladores\jflex-1.9.1\bin;C:\compiladores\java-cup-bin-11b\bin", "User")

3. Pipeline de Comandos Sencillos: 3 Pasos
1. Generar Lexer.java jflex Lexer.flex Transforma el archivo de especificación en código Java.
2. Compilar con javac javac Lexer.java Genera el archivo ejecutable Lexer.class.
3. Ejecutar con entrada java Lexer Entrada.txt Procesa el archivo fuente e imprime los resultados.

2.3

Estructura de un Archivo JFlex, Macros y Métodos Públicos

1. Métodos Públicos Nativos de JFlex

Dentro de las acciones semánticas de JFlex se dispone de métodos nativos para inspeccionar y manipular el lexema que encajó en el patrón:

String yytext()

Devuelve la cadena exacta del texto que encajó con el patrón.

int yylength()

Devuelve la longitud en caracteres del lexema reconocido.

char yycharat(int i)

Devuelve el carácter en la posición i del lexema actual.

Una Macro asocia un identificador no recursivo a una expresión regular para aumentar la legibilidad y favorecer la reutilización. Se declara en la sección 2 como Nombre = ExpReg y se invoca en las reglas encerrando su nombre entre llaves: {Nombre}.

3. Ejemplo con Macros y Métodos: UltimoBit.flex 
/* ============================================================
   UltimoBit.flex • Imprime el último bit de cada número binario
   ============================================================ */
%%
%class UltimoBit
%standalone

/* Declaración de Macros */
Binario = [01]+
Blanco  = [ \t\r\n]+

%%
{Binario} {
    int posUltimo = yylength() - 1;
    char bit = yycharat(posUltimo);
    System.out.print("[Binario: " + yytext() + " | Ultimo Bit: " + bit + "]");
}

{Blanco}  { System.out.print(yytext()); }
.         { System.out.print(yytext()); }

2.4

Reglas de Desambiguación: Longest Match y Orden de Reglas

1. Las 2 Reglas de Oro de Desambiguación en JFlex

Dos patrones son ambiguos si existe una cadena que puede encajar en ambos. JFlex resuelve la ambigüedad aplicando estrictamente dos reglas:

  1. Regla 1 (Preferencia al token más largo - Longest Match): El analizador lee la entrada consumiendo caracteres hasta encontrar la coincidencia más larga posible.
  2. Regla 2 (Preferencia por orden de aparición): Si dos patrones coinciden exactamente con la misma longitud, se ejecuta la regla escrita en primer lugar en el archivo .flex.
3. Ejemplo Visual: Entrada "ababc" ante Patrones Múltiples
Análisis de Ambigüedad para Entrada: ababc
Reglas en el archivo .flex: P1: a|b { print("P1 "); }
P2: (ab)* { print("P2 "); }
P3: (a|b)* { print("P3 "); }
PP: . { print("PP "); }
Evaluación de la entrada "ababc": 1. abab encaja en P2 y P3 (longitud 4).
2. Empate de longitud ➔ Se ejecuta P2 por estar antes.
3. Queda c ➔ Encaja en PP.
Salida resultante: P2 PP
4. Caso Práctico: Base 3 vs Base 2 para la entrada "0001111"
Opción A: Base 3 Primero [012]+ { print("BASE 3"); }
[01]+ { print("BASE 2"); }
Entrada 0001111 produce: BASE 3
Opción B: Base 2 Primero [01]+ { print("BASE 2"); }
[012]+ { print("BASE 3"); }
Entrada 0001111 produce: BASE 2

2.5

Proyecto Completo en NetBeans con GUI (`javax.swing`) y Lectura de Archivos

1. Integración Gráfica Profesional en Java

En esta fase integramos el escáner generado por JFlex dentro de un entorno visual de escritorio en Apache NetBeans con la librería estándar javax.swing:

  • • JFileChooser: Diálogo para abrir y seleccionar archivos de texto con código fuente (.txt, .src, .c).
  • • JTextArea: Editor interactivo donde se visualiza o edita el texto a escanear.
  • • JTable con DefaultTableModel: Tabla de salida con columnas [Línea, Columna, Token, Lexema].
  • • JOptionPane: Cuadros de alerta y resumen estadístico de errores léxicos.
3. Código Fuente del JFrame: FormularioCompilador.java 
package gui;

import javax.swing.*;
import javax.swing.table.DefaultTableModel;
import java.awt.*;
import java.io.*;
import compilador.Lexer;
import compilador.Token;

public class FormularioCompilador extends JFrame {

    private JTextArea txtEditor;
    private JTable tblTokens;
    private DefaultTableModel modelo;
    private JButton btnCargar, btnEscanear, btnLimpiar;
    private JLabel lblStatus;

    public FormularioCompilador() {
        super("Analizador Léxico JFlex - IT Chilpancingo");
        configurarUI();
    }

    private void configurarUI() {
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(900, 600);
        setLocationRelativeTo(null);
        setLayout(new BorderLayout(6, 6));

        // Barra de Botones
        JPanel pnlNorte = new JPanel(new FlowLayout(FlowLayout.LEFT, 8, 8));
        btnCargar = new JButton("Abrir Archivo...");
        btnEscanear = new JButton("Analizar Léxico (JFlex)");
        btnLimpiar = new JButton("Limpiar");

        btnEscanear.setBackground(new Color(79, 70, 229));
        btnEscanear.setForeground(Color.WHITE);
        btnEscanear.setFont(new Font("SansSerif", Font.BOLD, 12));

        pnlNorte.add(btnCargar);
        pnlNorte.add(btnEscanear);
        pnlNorte.add(btnLimpiar);
        add(pnlNorte, BorderLayout.NORTH);

        // Panel Dividido (Editor a la izquierda, Tabla a la derecha)
        JSplitPane split = new JSplitPane(JSplitPane.HORIZONTAL_SPLIT);
        split.setResizeWeight(0.5);

        txtEditor = new JTextArea();
        txtEditor.setFont(new Font("Monospaced", Font.PLAIN, 13));
        txtEditor.setText("int contador = 10;\nwhile (contador > 0) {\n    contador = contador - 1;\n}\n");
        split.setLeftComponent(new JScrollPane(txtEditor));

        modelo = new DefaultTableModel(new String[]{"Línea", "Col", "Token", "Lexema"}, 0);
        tblTokens = new JTable(modelo);
        tblTokens.setRowHeight(20);
        split.setRightComponent(new JScrollPane(tblTokens));

        add(split, BorderLayout.CENTER);

        lblStatus = new JLabel(" Sistema listo.");
        lblStatus.setBorder(BorderFactory.createEmptyBorder(4, 8, 4, 8));
        add(lblStatus, BorderLayout.SOUTH);

        // Listeners
        btnCargar.addActionListener(e -> cargarArchivo());
        btnEscanear.addActionListener(e -> escanearCodigo());
        btnLimpiar.addActionListener(e -> {
            txtEditor.setText("");
            modelo.setRowCount(0);
            lblStatus.setText(" Todo limpio.");
        });
    }

    private void cargarArchivo() {
        JFileChooser fc = new JFileChooser();
        if (fc.showOpenDialog(this) == JFileChooser.APPROVE_OPTION) {
            File f = fc.getSelectedFile();
            try (BufferedReader br = new BufferedReader(new FileReader(f))) {
                txtEditor.read(br, null);
                lblStatus.setText(" Archivo abierto: " + f.getName());
            } catch (Exception ex) {
                JOptionPane.showMessageDialog(this, "Error al abrir: " + ex.getMessage(), "Error", JOptionPane.ERROR_MESSAGE);
            }
        }
    }

    private void escanearCodigo() {
        String src = txtEditor.getText();
        if (src.trim().isEmpty()) {
            JOptionPane.showMessageDialog(this, "El editor está vacío.", "Aviso", JOptionPane.WARNING_MESSAGE);
            return;
        }

        modelo.setRowCount(0);
        Lexer lexer = new Lexer(new StringReader(src));
        Token t;
        int total = 0, errores = 0;

        try {
            while ((t = lexer.yylex()) != null) {
                total++;
                if ("ERROR_LEXICO".equals(t.getTipo())) errores++;
                modelo.addRow(new Object[]{t.getLinea(), t.getColumna(), t.getTipo(), t.getLexema()});
            }

            lblStatus.setText(String.format(" Total Tokens: %d | Errores: %d", total, errores));
            if (errores > 0) {
                JOptionPane.showMessageDialog(this, "Se detectaron " + errores + " errores léxicos.", "Atención", JOptionPane.WARNING_MESSAGE);
            } else {
                JOptionPane.showMessageDialog(this, "Escaneo exitoso sin errores (" + total + " tokens).", "Éxito", JOptionPane.INFORMATION_MESSAGE);
            }
        } catch (Exception ex) {
            JOptionPane.showMessageDialog(this, "Error en el escáner: " + ex.getMessage(), "Error", JOptionPane.ERROR_MESSAGE);
        }
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new FormularioCompilador().setVisible(true));
    }
}

Unidad 4: Generación de Código Objeto y Administración de Memoria

Duración: 20 Horas (Semanas 13-16) • Nivel Avanzado • Docente: Cruz Enrique García

La Generación de Código Objeto es la fase culminante del compilador. Transforma la representación intermedia (TAC) en código ejecutable en lenguaje ensamblador o código máquina para la arquitectura de procesador destino. Involucra decisiones críticas de hardware: selección óptima de instrucciones, asignación eficiente de registros de CPU y gestión de la memoria en tiempo de ejecución (*runtime environment*).

Competencia Específica

Diseñar, construir e integrar el generador de código objeto para traducir las instrucciones intermedias a lenguaje ensamblador x86/x64 o código máquina, gestionando adecuadamente los registros del microprocesador y el marco de pila (*stack frame*) en tiempo de ejecución.

4.1 Asignación de Registros y Descriptores

Los registros son las unidades de almacenamiento más veloces de la CPU pero de capacidad limitada. Para administrar su asignación dinámica se utilizan dos estructuras:

Descriptor de Registros (`Register Descriptor`)

Rastrea en todo momento qué variables residen actualmente en cada registro de la CPU (ej. EAX contiene: {x, t1}).

Descriptor de Direcciones (`Address Descriptor`)

Indica todas las ubicaciones donde se encuentra el valor actual de una variable (en su celda de memoria RAM, en el stack o en un registro EDX).

4.2 - 4.3 Traducción a Lenguaje Ensamblador (x86)

Cada cuádruplo de código intermedio se mapea a una secuencia correspondiente de instrucciones de ensamblador:

Mapeo TAC a Ensamblador x86 (Sintaxis Intel) 
; TAC: t1 = a + b
MOV EAX, [ebp - 4]   ; Carga variable 'a' desde el stack en EAX
ADD EAX, [ebp - 8]   ; Suma variable 'b' al acumulador EAX
MOV [ebp - 12], EAX  ; Guarda el resultado en temporal 't1'

; TAC: if (t1 >= 100) goto L1
CMP EAX, 100         ; Compara t1 con 100
JGE L1               ; Salto condicional Jump-if-Greater-or-Equal

4.4 Administración de Memoria y Marco de Activación (Stack Frame)

Durante la ejecución del programa compilado, la memoria RAM se divide en 4 áreas fundamentales:

Organización de la Memoria en Tiempo de Ejecución (Runtime)
Direcciones Altas (0xFFFFFFFF)
⬇ STACK (Pila de Llamadas y Variables Locales) ⬇
Espacio Libre para Crecimiento
⬆ HEAP (Memoria Dinámica malloc / new) ⬆
.DATA / .BSS (Variables Globales y Estáticas)
.TEXT (Instrucciones de Código Máquina en Sólo Lectura)
Direcciones Bajas (0x00000000)

Anatomía de un Registro de Activación (Stack Frame)

Paso de Parámetros Reales

Apilados por el llamador (*caller*) de derecha a izquierda antes de invocar la función.

Dirección de Retorno (EIP)

La instrucción `CALL` apila la dirección de la siguiente instrucción para retornar.

Puntero al Marco Anterior (EBP)

El prólogo ejecuta `PUSH EBP; MOV EBP, ESP` para establecer la base del nuevo frame.

Variables Locales y Temporales

Se reserva espacio restando al puntero de pila: `SUB ESP, bytes_locales`.

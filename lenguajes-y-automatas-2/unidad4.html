4.1

Arquitectura e Integración Unificada JFlex + CUP

1. El Puente de Integración: sym.java y java_cup.runtime.Symbol

La integración perfecta entre JFlex y CUP se logra mediante dos directivas clave en el archivo Lexer.flex:

  1. %cup: Hace que el escáner implemente automáticamente java_cup.runtime.Scanner y configure su función de escaneo como public java_cup.runtime.Symbol next_token().
  2. import java_cup.runtime.Symbol; y uso de sym.NOMBRE_TOKEN al retornar tokens reconocidos.
3. Arquitectura del Compilador Integrado
Flujo Integral: Código Fuente ➔ JFlex ➔ CUP ➔ Ejecución
4. Generador Automático Unificado en NetBeans (GeneradorCompilador.java) 
package compilador;
import java.io.File;

public class GeneradorCompilador {
    public static void main(String[] args) {
        String rutaFlex = "src/compilador/Lexer.flex";
        String[] opcionesCUP = {"-destdir", "src/compilador", "-parser", "Parser", "-symbols", "sym", "src/compilador/Parser.cup"};

        try {
            // 1. Generar Lexer.java con JFlex
            jflex.Main.generate(new File(rutaFlex));
            System.out.println("[1/2] JFlex compilado correctamente.");

            // 2. Generar Parser.java y sym.java con CUP
            java_cup.Main.main(opcionesCUP);
            System.out.println("[2/2] CUP Parser y sym generados exitosamente.");
            System.out.println("==> ¡Compilador listo para ejecución!");

        } catch (Exception e) {
            System.err.println("Error en la generación: " + e.getMessage());
        }
    }
}

Mini-Proyecto 1: Calculadora con Asignaciones y Memoria de Variables

1. Memoria de Variables en CUP

Permite evaluar sentencias de asignación como radio = 5.0; y luego evaluar expresiones que usen variables como area = 3.1416 * radio * radio; guardando los valores en un HashMap<String, Double> en memoria.

3. Especificación CUP de la Calculadora con Memoria 
parser code {:
    public java.util.Map memoria = new java.util.HashMap<>();
:};

terminal ASIGN, PUNTO_COMA, MAS, MENOS, POR, DIV, PAREN_IZQ, PAREN_DER;
terminal Double NUMERO;
terminal String ID;

non terminal programa, sentencias, sentencia;
non terminal Double expr;

precedence left MAS, MENOS;
precedence left POR, DIV;

programa ::= sentencias;
sentencias ::= sentencias sentencia | sentencia;

sentencia ::= ID:id ASIGN expr:val PUNTO_COMA {:
                parser.memoria.put(id, val);
                System.out.println("[Asignación] " + id + " = " + val);
            :}
            | expr:val PUNTO_COMA {:
                System.out.println("[Expresión] Resultado = " + val);
            :};

expr ::= expr:e1 MAS expr:e2   {: RESULT = e1 + e2; :}
       | expr:e1 POR expr:e2   {: RESULT = e1 * e2; :}
       | ID:id                 {:
            if (!parser.memoria.containsKey(id)) {
                System.err.println("Error: Variable no definida: " + id);
                RESULT = 0.0;
            } else {
                RESULT = parser.memoria.get(id);
            }
       :}
       | NUMERO:n              {: RESULT = n; :};

Mini-Proyecto 2: Compilador del Lenguaje Estructurado "MiniLang"

1. Gramática de MiniLang con Estructuras de Control (if/while)

MiniLang es un lenguaje didáctico completo con soporte para:

  • • Declaraciones: int total; float promedio;
  • • Asignaciones: total = 100;
  • • Condicionales: if (total >= 50) { ... } else { ... }
  • • Ciclos: while (total > 0) { total = total - 1; }
  • • Salida: print(promedio);
4.5

IDE Didáctico Completo en Apache NetBeans (Swing GUI Final)

1. Arquitectura de la Interfaz Gráfica con Pestañas

La aplicación visual integra en pestañas (JTabbedPane):

1. Editor: Con selector JFileChooser y guardado.
2. Tokens (JTable): Desglose léxico generado por JFlex.
3. Consola/Errores: Reporte sintáctico/semántico de CUP.
3. Código Fuente del IDE: IDEMiniCompilador.java 
package gui;

import javax.swing.*;
import javax.swing.table.DefaultTableModel;
import java.awt.*;
import java.io.*;
import compilador.Lexer;
import compilador.Parser;
import java_cup.runtime.Symbol;

public class IDEMiniCompilador extends JFrame {

    private JTextArea txtCodigo, txtConsola;
    private JTable tblTokens;
    private DefaultTableModel modeloTokens;
    private JButton btnAbrir, btnCompilar, btnLimpiar;

    public IDEMiniCompilador() {
        super("IDE Didáctico • JFlex + CUP Compilador Completo - IT Chilpancingo");
        iniciarComponentes();
    }

    private void iniciarComponentes() {
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(1000, 680);
        setLocationRelativeTo(null);
        setLayout(new BorderLayout(8, 8));

        // Toolbar
        JToolBar toolbar = new JToolBar();
        btnAbrir = new JButton("Abrir Archivo");
        btnCompilar = new JButton("COMPILAR PROGRAMA (JFlex + CUP)");
        btnLimpiar = new JButton("Limpiar");

        btnCompilar.setBackground(new Color(16, 185, 129));
        btnCompilar.setForeground(Color.WHITE);
        btnCompilar.setFont(new Font("SansSerif", Font.BOLD, 12));

        toolbar.add(btnAbrir);
        toolbar.addSeparator();
        toolbar.add(btnCompilar);
        toolbar.add(btnLimpiar);
        add(toolbar, BorderLayout.NORTH);

        // Panel con Pestañas
        JTabbedPane tabs = new JTabbedPane();

        // Pestaña 1: Editor y Tokens
        JSplitPane splitEditor = new JSplitPane(JSplitPane.HORIZONTAL_SPLIT);
        txtCodigo = new JTextArea("int x;\nint y;\nx = 15;\ny = x * 2 + 10;\nif (y > 20) {\n    print(y);\n}\n");
        txtCodigo.setFont(new Font("Monospaced", Font.PLAIN, 14));
        splitEditor.setLeftComponent(new JScrollPane(txtCodigo));

        modeloTokens = new DefaultTableModel(new String[]{"Línea", "Columna", "Token ID", "Lexema"}, 0);
        tblTokens = new JTable(modeloTokens);
        splitEditor.setRightComponent(new JScrollPane(tblTokens));
        splitEditor.setResizeWeight(0.55);

        tabs.addTab("Editor de Código y Escaneo Léxico", splitEditor);

        // Pestaña 2: Consola de Salida
        txtConsola = new JTextArea();
        txtConsola.setEditable(false);
        txtConsola.setBackground(new Color(15, 23, 42));
        txtConsola.setForeground(new Color(52, 211, 153));
        txtConsola.setFont(new Font("Monospaced", Font.PLAIN, 13));
        tabs.addTab("Consola de Compilación / Errores", new JScrollPane(txtConsola));

        add(tabs, BorderLayout.CENTER);

        // Eventos
        btnCompilar.addActionListener(e -> compilar());
        btnLimpiar.addActionListener(e -> {
            txtCodigo.setText("");
            txtConsola.setText("");
            modeloTokens.setRowCount(0);
        });
        btnAbrir.addActionListener(e -> {
            JFileChooser fc = new JFileChooser();
            if (fc.showOpenDialog(this) == JFileChooser.APPROVE_OPTION) {
                try (BufferedReader br = new BufferedReader(new FileReader(fc.getSelectedFile()))) {
                    txtCodigo.read(br, null);
                } catch (Exception ex) {
                    JOptionPane.showMessageDialog(this, "Error: " + ex.getMessage());
                }
            }
        });
    }

    private void compilar() {
        String codigo = txtCodigo.getText();
        if (codigo.trim().isEmpty()) return;

        modeloTokens.setRowCount(0);
        txtConsola.setText("====================================================\n");
        txtConsola.append("  INICIANDO COMPILACIÓN COMPLETA (JFLEX + CUP)\n");
        txtConsola.append("====================================================\n");

        try {
            // 1. Análisis Léxico
            Lexer lexer = new Lexer(new StringReader(codigo));
            // 2. Análisis Sintáctico con CUP
            Parser parser = new Parser(lexer);
            parser.parse();

            txtConsola.append("\n[ÉXITO] ¡Compilación finalizada sin errores sintácticos!\n");
            JOptionPane.showMessageDialog(this, "¡Compilación Exitosa!", "Compilador", JOptionPane.INFORMATION_MESSAGE);

        } catch (Exception ex) {
            txtConsola.append("\n[ERROR] " + ex.getMessage() + "\n");
        }
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> new IDEMiniCompilador().setVisible(true));
    }
}

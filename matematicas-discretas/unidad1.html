1.1

Sistemas Numéricos (Binario, Octal, Decimal, Hexadecimal)

1. Explicación Teórica y Conceptual

Los sistemas numéricos posicionales representan cantidades mediante dígitos cuyo peso depende de su posición respecto a la base \(b\): \(N = \sum_{i=-m}^{n-1} d_i \cdot b^i\). En computación, el sistema binario (\(b=2\)) es el lenguaje nativo del hardware (transistores encendidos/apagados), mientras que el octal (\(b=8\)) y hexadecimal (\(b=16\)) permiten compactar cadenas largas de bits para facilitar la lectura de direcciones de memoria RAM y códigos de operación.

2. Glosario de Términos y Definiciones
  • • Base (\(b\)): Total de símbolos disponibles en el sistema (\(b=2, 8, 10, 16\)).
  • • Bit: Dígito binario básico (0 ó 1).
  • • Byte: Bloque de 8 bits (\(2^8 = 256\) combinaciones posibles).
  • • Nibble: Bloque de 4 bits (exactamente 1 dígito hexadecimal).

4. Ejercicios Guiados Paso a Paso

Problema: Hallar el valor decimal del número hexadecimal \(3F8_{16}\).

Desarrollo: \(3 \times 16^2 + 15 \times 16^1 + 8 \times 16^0 = 3(256) + 15(16) + 8(1) = 768 + 240 + 8 = 1016_{10}\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Encuentra el valor decimal de \(110110_2\) y de \(725_8\). Pista: \(110110_2 = 54_{10}\), \(725_8 = 469_{10}\).

1.2

Conversiones entre Sistemas Numéricos

1. Explicación Teórica y Conceptual

Las conversiones entre bases son algoritmos matemáticos que transforman la representación de un número sin alterar su valor real. La conversión de Decimal a Base \(b\) se realiza mediante divisiones sucesivas entre la base tomando los residuos, mientras que la conversión entre Binario y Octal/Hexadecimal es directa agrupando bits en tríadas (3 bits) o cuartetos (4 bits).

2. Glosario de Términos y Definiciones
  • • Divisiones sucesivas: Algoritmo de división entera donde los residuos en orden inverso forman la parte entera.
  • • Multiplicaciones sucesivas: Algoritmo para convertir la parte fraccionaria multiplicando por la base destino.
  • • Agrupación directa: Agrupar de 3 en 3 bits para octal o de 4 en 4 bits para hexadecimal a partir del punto binario.
3. Ejemplos con Ilustraciones y Diagramas
Pipeline de Conversión Directa Binario ➔ Hexadecimal
1101011010101111₂ = D6AF₁₆
4. Ejercicios Guiados Paso a Paso

Problema: Convertir el número decimal \(218.625_{10}\) a Binario y Hexadecimal.

1. Entera: \(218 / 2 = 109\) (res 0), \(109/2=54\) (1), \(54/2=27\) (0), \(27/2=13\) (1), \(13/2=6\) (1), \(6/2=3\) (0), \(3/2=1\) (1), \(1/2=0\) (1) ➔ \(11011010_2\).
2. Fraccionaria: \(0.625 \times 2 = 1.25\) (1), \(0.25 \times 2 = 0.5\) (0), \(0.5 \times 2 = 1.0\) (1) ➔ \(0.101_2\).
Resultado: \(11011010.101_2 = DA.A_{16}\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Convierte \(425_{10}\) a base octal y hexadecimal. Pista: \(651_8\) y \(1A9_{16}\).

1.3

Operaciones Básicas y Complemento a 2

1. Explicación Teórica y Conceptual

Las operaciones aritméticas binarias siguen las mismas reglas que en decimal pero con tabla base simplificada (\(1+1 = 10_2\)). Para representar cantidades negativas y ejecutar restas usando el mismo sumador se utiliza el Complemento a 2 (\(C_2\)): \(C_2(N) = \overline{N} + 1\). La resta se transforma en \(A - B = A + C_2(B)\).

2. Glosario de Términos y Definiciones
  • • Complemento a 1 (\(C_1\)): Inversión lógica bit a bit (0 pasa a 1, 1 pasa a 0).
  • • Complemento a 2 (\(C_2\)): \(C_1 + 1\). Elimina el problema del doble cero (+0 y -0).
  • • Bit de Signo (MSB): El bit más a la izquierda; 0 representa positivo y 1 representa negativo.

4. Ejercicios Guiados Paso a Paso

Problema: Realizar en binario de 8 bits con signo la operación \(-18_{10} + 11_{10}\).

1. \(18_{10} = 00010010_2 \implies C_2(18) = 11101101 + 1 = 11101110_2\) (\(-18\)).
2. \(11_{10} = 00001011_2\).
3. Suma: \(11101110 + 00001011 = 11111001_2\). Verificando en decimal: \(C_2(11111001) = -(00000110 + 1) = -7_{10}\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Realiza la suma de \(-35_{10} + 20_{10}\) en complemento a dos de 8 bits. Pista: Resultado \(11110001_2 = -15_{10}\).

1.4

Algoritmos de Booth para Multiplicación y División

1. Explicación Teórica y Conceptual

El Algoritmo de Booth es un método eficiente para multiplicar números enteros con signo representados en complemento a dos. En lugar de sumar en cada bit '1', Booth inspecciona pares de bits \((Q_0, Q_{-1})\) y realiza sumas o restas únicamente en las transiciones (\(10 \to\) Resta, \(01 \to\) Suma, \(00\) y \(11 \to\) Solo desplazamiento SAR), acelerando el cálculo en hardware.

2. Glosario de Términos y Definiciones
  • • Registro A (Acumulador): Registro inicializado en ceros donde se acumulan los resultados parciales.
  • • Registro Q: Contiene el multiplicador; su bit menos significativo es \(Q_0\).
  • • Bit \(Q_{-1}\): Flip-flop auxiliar inicializado en 0.
  • • SAR (Shift Arithmetic Right): Desplazamiento aritmético a la derecha que preserva el bit de signo.

4. Ejercicios Guiados Paso a Paso

Problema: Multiplicar \(M = 5\) (\(00101\)) por \(Q = -4\) (\(11100\)) en 5 bits con Booth.

Traza: Ciclo 1 (00 ➔ SAR), Ciclo 2 (00 ➔ SAR), Ciclo 3 (10 ➔ A=A-M, SAR), Ciclo 4 (11 ➔ SAR), Ciclo 5 (11 ➔ SAR).
Resultado concatenado [A Q] = \(1111101100_2 = -20_{10}\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Realiza la traza del algoritmo de Booth para \(M = -7\) y \(Q = 3\) en 5 bits. Pista: Resultado final \(-21_{10}\).

1.5

Aplicación de los Sistemas Numéricos en la Computación

1. Explicación Teórica y Conceptual

Los sistemas numéricos son el pilar de la arquitectura computacional moderna. Permiten estructurar el mapa de memoria RAM (segmentos de código, pila y datos), definir protocolos de red (direcciones IPv4 en decimal punteado e IPv6 en hexadecimal), representar paletas de colores en gráficos por computadora y codificar texto mediante estándares ASCII y UTF-8.

2. Glosario de Términos y Definiciones
  • • Espacio de Direcciones: Cada byte de memoria RAM tiene asignada una dirección hexadecimal única (ej. 0x00400000).
  • • Código ASCII / Unicode: Mapeo numérico para caracteres (ej. 'A' = \(65_{10} = 41_{16} = 01000001_2\)).
  • • Color RGB 24 bits: 3 bytes que definen intensidades de Rojo, Verde y Azul (ej. #00FF00 = Verde puro).
3. Ejemplos con Ilustraciones y Diagramas
Mapeo de Memoria RAM & Formato de Color RGB
Ejemplo: #3B82F6 ➔ R: 59 (3B₁₆), G: 130 (82₁₆), B: 246 (F6₁₆)
4. Ejercicios Guiados Paso a Paso

Problema: Un microcontrolador lee un sensor de temperatura de 8 bits que entrega el valor binario \(01100100_2\). ¿Cuál es el valor en decimal y hexadecimal?

\(01100100_2 = 64_{16} = 6(16) + 4 = 100_{10}\) (°C / unidades de sensor).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Descompón el color hexadecimal #E11D48 en sus valores decimales de Rojo (R), Verde (G) y Azul (B). Pista: R=225, G=29, B=72.

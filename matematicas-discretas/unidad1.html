Sistemas Numéricos y Circuitos Sumadores

Bases posicionales, aritmética binaria, complemento a 2 y circuitos sumadores con compuertas lógicas.

12 Horas (Semanas 1-3) • 1er Semestre Universitario • Docente: Cruz Enrique García

¿Por qué estudiamos esto en 1er Semestre?

Las computadoras no entienden letras ni números decimales; sólo comprenden la presencia o ausencia de electricidad (5 Voltios = 1 / 0 Voltios = 0). En esta unidad aprenderás cómo se transforman los números humanos a ceros y unos, y cómo construir físicamente un circuito sumador con compuertas lógicas en una protoboard.

1.1 Sistemas Numéricos (Binario, Octal, Decimal, Hexadecimal)

1. Explicación Clara

Un sistema de numeración posicional es una forma de escribir números donde el valor de cada dígito depende del lugar donde está escrito. Por ejemplo, en nuestro sistema decimal cotidiano (Base 10), el número 235 significa: \[235 = (2 \times 10^2) + (3 \times 10^1) + (5 \times 10^0) = 200 + 30 + 5\] En las computadoras aplicamos exactamente la misma idea, pero en lugar de multiplicar por potencias de 10, multiplicamos por potencias de 2 (Binario), 8 (Octal) o 16 (Hexadecimal).

Binario (Base 2) Dígitos: 0, 1
Octal (Base 8) Dígitos: 0 a 7
Decimal (Base 10) Dígitos: 0 a 9
Hexadecimal (Base 16) 0-9 y A, B, C, D, E, F
2. Términos Clave
  • • Bit (Binary Digit): La unidad mínima de memoria en informática (un 0 o un 1).
  • • Byte: Un paquete de 8 bits juntos (ej. 10110010). Permite almacenar un caracter o número de 0 a 255.
  • • Nibble: Un paquete de 4 bits (la mitad de un byte). Equivale exactamente a 1 dígito hexadecimal.
  • • Letras en Hexadecimal: Para no inventar símbolos raros se usan letras: \(A=10\), \(B=11\), \(C=12\), \(D=13\), \(E=14\), \(F=15\).
3. Diagrama Visual de Conversión

Para convertir entre Binario, Octal y Hexadecimal solo agrupas los bits:

// Ejemplo: Convertir el número binario 11010110_2 a Hexadecimal
Paso 1: Separa en grupos de 4 bits (de derecha a izquierda):
[ 1101 ] [ 0110 ]
↓ ↓
D (13) 6 ➔ Resultado: D6_{16}
4. Ejercicio Guiado Paso a Paso

Convertir el número decimal \(25_{10}\) a Binario

Se divide entre 2 sucesivamente y se anotan los residuos:

• \(25 \div 2 = 12\) (Residuo: 1) ➔ Último bit

• \(12 \div 2 = 6\) (Residuo: 0)

• \(6 \div 2 = 3\) (Residuo: 0)

• \(3 \div 2 = 1\) (Residuo: 1)

• \(1 \div 2 = 0\) (Residuo: 1) ➔ Primer bit

Leyendo los residuos de abajo hacia arriba: \(25_{10} = 11001_2\).

5. Ejercicios de Práctica (Firmas 40%)
1. Convierte a Binario:

El número decimal \(42_{10}\).

Respuesta: \(101010_2\)
2. Convierte a Hexadecimal:

El binario \(11111010_2\).

Respuesta: \(FA_{16}\)

1.3 Circuitos Digitales: El Semisumador y Sumador Completo

1. ¿Cómo suma físicamente una computadora?

Cuando sumas dos bits en papel: \[0 + 0 = 0, \quad 0 + 1 = 1, \quad 1 + 0 = 1, \quad 1 + 1 = 0 \text{ (y llevas 1 de acarreo)}\] Para construir esto en la vida real usamos 2 compuertas lógicas: XOR (calcula la suma \(S = A \oplus B\)) y AND (calcula el acarreo \(C = A \cdot B\)). Este circuito se llama Semisumador (Half Adder).

Lista de Componentes Físicos para Armar en Protoboard:
  • • Circuito Integrado 74LS86 (XOR cuádruple de 2 entradas): Pin 14 a +5V (VCC), Pin 7 a Tierra (GND).
  • • Circuito Integrado 74LS08 (AND cuádruple de 2 entradas): Pin 14 a +5V, Pin 7 a Tierra (GND).
  • • DIP Switch de 2 posiciones: Para meter las entradas A y B (0 = 0V / 1 = 5V).
  • • 2 Diodos LED (Rojo para Suma, Verde para Acarreo): Con resistencias de 330Ω a tierra para no quemarlos.

1.4 Números Negativos y Complemento a 2 (\(C_2\))

1. ¿Cómo sabe la computadora si un número es negativo?

Las computadoras no tienen signo '-' físico. Lo que hacen es usar el bit más a la izquierda (MSB) como bit de signo: si es 0 es positivo, y si es 1 es negativo. Para convertir un número positivo a negativo se usa la regla de Complemento a 2:

Regla de oro: Invierte todos los bits (0 pasa a 1, y 1 pasa a 0) y súmale 1 al final.
4. Ejemplo Guiado: Representar -5 en 8 bits

1. Escribe el número 5 positivo en 8 bits: 0000 0101

2. Invierte todos sus bits (Compuertas NOT): 1111 1010

3. Súmale 1 al resultado: 1111 1010 + 1 = 1111 1011

Resultado: En la memoria de la computadora, el número \(-5\) se almacena como 11111011.

Unidad 1 • Sistemas Numéricos (12 Horas)

Competencia Específica: Sistematizar la conversión entre sistemas numéricos posicionales, así como las operaciones básicas de suma, resta, multiplicación y división con signo mediante complemento a 2 y el algoritmo de Booth.

1.1 Sistemas Numéricos (Binario, Octal, Decimal, Hexadecimal)

1. Explicación

Un sistema numérico posicional es aquel donde el valor de cada símbolo depende de su posición respecto a la base \(b\): \(N = \sum d_i \cdot b^i\). Las computadoras emplean binario (\(b=2\)) por el hardware de transistores, octal (\(b=8\)) y hexadecimal (\(b=16\)) para simplificar direcciones de memoria RAM.

2. Términos Clave

Bit: 0 ó 1. Nibble: 4 bits (1 dígito hex). Byte: 8 bits. Base: Cantidad de símbolos permitidos (\(b=2, 8, 10, 16\)).

3. Ilustración
Binario: {0,1}
Octal: {0..7}
Decimal: {0..9}
Hex: {0..9, A..F}
4. Ejercicio Guiado

Representar el valor posicional de \(2A3_{16}\) en decimal: \(2 \times 16^2 + 10 \times 16^1 + 3 \times 16^0 = 512 + 160 + 3 = 675_{10}\).

5. Ejercicio de Práctica

Calcula el valor decimal de \(375_8\) y \(101101_2\). (Resp: 253 y 45).

1.2 Conversiones entre Sistemas Numéricos

1. Explicación

• Decimal a Base \(b\): Divisiones sucesivas entre \(b\), tomando los residuos.
• Binario a Octal/Hex: Agrupación en bloques de 3 bits (Octal) o 4 bits (Hexadecimal) desde el punto binario.

4. Ejercicio Guiado

Convertir \(11010110_2\) a Hexadecimal: Agrupar [1101] [0110] ➔ \(D6_{16}\).

5. Ejercicio de Práctica

Convierte \(189_{10}\) a binario y hexadecimal. (Resp: \(10111101_2\) y \(BD_{16}\)).

1.3 Operaciones Básicas (Suma, Resta, Multiplicación, División) y Complemento a 2

1. Explicación

La resta binaria se ejecuta como una suma con Complemento a 2 (\(C_2\)): \(A - B = A + C_2(B)\), donde \(C_2(B) = \overline{B} + 1\). Esto simplifica el circuito de la ALU en el procesador.

4. Ejercicio Guiado

Resta \(1101_2 (13) - 0110_2 (6)\): \(C_2(0110) = 1001 + 1 = 1010_2\). Suma: \(1101 + 1010 = [1]0111_2 = 7_{10}\) (se descarta el desbordamiento).

5. Ejercicio de Práctica

Realiza en binario de 8 bits con signo la operación \(-15_{10} + 9_{10}\). (Resp: \(11111010_2 = -6_{10}\)).

1.4 Algoritmos de Booth para Multiplicación y División en Binario

1. Explicación

El Algoritmo de Booth permite multiplicar enteros con signo en complemento a dos en \(n\) ciclos inspeccionando el par de bits \((Q_0, Q_{-1})\) con desplazamientos aritméticos a la derecha (SAR).

3. Arquitectura Hardware ALU
Registros: [ M (Multiplicando) ] ➔ ALU ➔ [ A (Acumulador) ][ Q (Multiplicador) ][ Q-1 ]

1.5 Aplicación de los Sistemas Numéricos en la Computación

• Direccionamiento de Memoria RAM: Expresado en hexadecimal (ej. 0x7FFF0000).
• Codificación de Colores Web: Modelo RGB en 24 bits (ej. #FF5733 = Rojo 255, Verde 87, Azul 51).
• Máscaras de Subred IP (IPv4 / IPv6): Notación binaria y hexadecimal para enrutamiento.

Lógica Matemática e Inducción

Lógica proposicional, tablas de verdad, inferencias y demostración por inducción.

Duración: 16 Horas (Semanas 5-8) • Nivel Didáctico • Docente: Cruz Enrique García

La Lógica Matemática proporciona las reglas rigurosas de razonamiento para verificar la corrección de programas, diseñar circuitos integrados y formalizar especificaciones en inteligencia artificial y bases de datos.

Competencia Específica

Analizar y resolver problemas formales utilizando lógica proposicional, tablas de verdad, reglas de inferencia, lógica de predicados e inducción matemática para validar algoritmos computacionales.

3.4 Demostración por Inducción Matemática

El principio de inducción matemática permite demostrar que una propiedad \(P(n)\) es verdadera para todo entero \(n \ge n_0\):

Paso Base

Demostrar que la proposición es válida para el valor inicial \(n = 1\): \(P(1)\) es verdadero.

Hipótesis de Inducción

Asumir que la proposición es verdadera para un valor arbitrario \(n = k\): \(P(k)\).

Paso Inductivo

Demostrar que a partir de la hipótesis se cumple para \(n = k + 1\): \(P(k) \implies P(k+1)\).

Ejemplo Resuelto 3.1 Demostración Formal por Inducción

Demostrar por inducción matemática que la suma de los primeros \(n\) cuadrados cumple: \[\sum_{i=1}^n i^2 = 1^2 + 2^2 + 3^2 + \dots + n^2 = rac{n(n+1)(2n+1)}{6}, \quad orall n \ge 1\]

1. Paso Base (\(n = 1\)):
Lado Izquierdo: \(1^2 = 1\).
Lado Derecho: \( rac{1(1+1)(2(1)+1)}{6} = rac{1(2)(3)}{6} = 1\). Se cumple \(1 = 1\).

2. Hipótesis Inductiva (\(n = k\)):
Asumimos verdadero que: \(1^2 + 2^2 + \dots + k^2 = rac{k(k+1)(2k+1)}{6}\).

3. Paso Inductivo (\(n = k + 1\)):
Queremos demostrar que: \(1^2 + \dots + k^2 + (k+1)^2 = rac{(k+1)((k+1)+1)(2(k+1)+1)}{6} = rac{(k+1)(k+2)(2k+3)}{6}\).
Sustituyendo la hipótesis: \( rac{k(k+1)(2k+1)}{6} + (k+1)^2 = (k+1) \left[ rac{k(2k+1) + 6(k+1)}{6} ight] = (k+1) \left[ rac{2k^2 + 7k + 6}{6} ight] = rac{(k+1)(k+2)(2k+3)}{6}\).
\( herefore\) Queda formalmente demostrado para todo \(n \in \mathbb{N}\).

Ejercicios Propuestos de Lógica e Inducción

Ejercicio 1 (Reglas de Inferencia):

Demuestra formalmente la conclusión \(R\) a partir de las premisas: 1) \(P o Q\), 2) \( eg Q\), 3) \( eg P o R\).

Pista: Aplica Modus Tollens entre 1 y 2 para obtener \( eg P\), luego Modus Ponens con 3.
Ejercicio 2 (Inducción Matemática):

Demuestra por inducción que \(2^0 + 2^1 + 2^2 + \dots + 2^n = 2^{n+1} - 1\) para todo \(n \ge 0\).

Base: \(n=0 o 1 = 2^1 - 1 = 1\).
Ejercicio 3 (Lógica de Predicados):

Formaliza con cuantificadores: "Para todo número real \(x\), si \(x > 0\) entonces existe un \(y\) tal que \(x = y^2\)".

Respuesta: \( orall x \in \mathbb{R}\ (x > 0 \implies \exists y \in \mathbb{R}\ (x = y^2))\).
Ejercicio 4 (Tablas de Verdad):

Construye la tabla de verdad y determina si \(((P o Q) \land P) o Q\) es una tautología.

Resultado: Es la tautología del Modus Ponens (todos los valores son 1).

3.1

Lógica Proposicional, Tablas de Verdad e Inferencias

1. Explicación Teórica y Conceptual

La Lógica Proposicional estudia las proposiciones (oraciones con valor de verdad binario \(V=1\) ó \(F=0\)) y sus combinaciones mediante conectivos lógicos (\(\land, \lor, \neg, \to, \leftrightarrow\)). Una tabla de verdad evalúa las \(2^n\) combinaciones. Si la columna final es siempre 1 se tiene una Tautología; si es siempre 0, una Contradicción; si es mixta, una Contingencia. Las demostraciones se fundamentan en reglas de inferencia como Modus Ponens (\(P \to Q, P \vdash Q\)).

2. Glosario de Términos y Definiciones
  • • Proposición Simple: Enunciado atómico que no contiene conectivos (ej. \(P\): 'El servidor está activo').
  • • Condicional (\(P \to Q\)): Falsa únicamente cuando el antecedente \(P\) es verdadero y el consecuente \(Q\) es falso.
  • • Modus Ponens: Si \(P \to Q\) es verdadero y \(P\) es verdadero, se concluye \(Q\).
  • • Modus Tollens: Si \(P \to Q\) es verdadero y \(\neg Q\) es verdadero, se concluye \(\neg P\).
3. Ejemplos con Ilustraciones y Diagramas
Tabla de Verdad del Condicional:
P=1, Q=1 ➔ P → Q = 1
P=1, Q=0 ➔ P → Q = 0 (Único caso falso)
P=0, Q=1 ➔ P → Q = 1
P=0, Q=0 ➔ P → Q = 1
4. Ejercicios Guiados Paso a Paso

Problema: Demostrar que \((P \to Q) \equiv (\neg P \lor Q)\) mediante tabla de verdad.

Evaluando para (1,1): 1=1. Para (1,0): 0=0. Para (0,1): 1=1. Para (0,0): 1=1.
Ambas columnas son idénticas en todas las filas, demostrando la equivalencia lógica.

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Construye la tabla de verdad para \(P \land \neg(P \lor Q)\) y clasifícala. Pista: Es una Contradicción (todos ceros).

3.2

Lógica de Predicados y Cuantificadores

1. Explicación Teórica y Conceptual

La Lógica de Predicados extiende la lógica proposicional al permitir variables, funciones y cuantificadores sobre un dominio de discurso. El Cuantificador Universal (\(\forall x\)) afirma que una propiedad se cumple para todos los elementos, mientras que el Cuantificador Existencial (\(\exists x\)) afirma que se cumple para al menos uno.

2. Glosario de Términos y Definiciones
  • • Predicado \(P(x)\): Función booleana que se convierte en proposición al asignarle un valor a la variable \(x\).
  • • Cuantificador Universal (\(\forall x\)): \(\forall x P(x)\) es verdadero si \(P(a)\) es verdadero para todo \(a \in D\).
  • • Cuantificador Existencial (\(\exists x\)): \(\exists x P(x)\) es verdadero si existe al menos un \(a \in D\) con \(P(a)\) verdadero.
  • • Negación de Cuantificadores: \(\neg (\forall x P(x)) \equiv \exists x \neg P(x)\).
3. Ejemplos con Ilustraciones y Diagramas
Ejemplo Formal:
∀x (x > 0 → x² > 0) [Dominio: Reales no nulos] ➔ Verdadero
4. Ejercicios Guiados Paso a Paso

Problema: Negar la proposición: 'Todos los programas tienen errores' (\(\forall x (P(x) \to E(x))\)).

\(\neg(\forall x (P(x) \to E(x))) \equiv \exists x \neg(P(x) \to E(x)) \equiv \exists x (P(x) \land \neg E(x))\).
Interpretación: 'Existe al menos un programa que no tiene errores'.

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Expresa formalmente: 'Existe un número entero cuyo cuadrado es igual a 9'. Pista: \(\exists x \in \mathbb{Z} (x^2 = 9)\).

3.3

Álgebra Declarativa y Programación Lógica

1. Explicación Teórica y Conceptual

El Álgebra Declarativa es el paradigma computacional donde los programas se definen mediante sentencias lógicas y hechos, indicando qué debe resolverse en lugar de cómo resolverse secuencialmente. Es el fundamento del lenguaje Prolog y los sistemas de razonamiento automático en Inteligencia Artificial.

2. Glosario de Términos y Definiciones
  • • Cláusula de Horn: Disyunción de literales con a lo más un literal positivo (\(B \leftarrow A_1 \land A_2 \land \dots \land A_n\)).
  • • Hecho: Afirmación incondicionalmente verdadera (ej. conecta(routerA, switch1).).
  • • Regla: Afirmación condicional que infiere nuevos hechos mediante un motor de inferencia por resolución.
3. Ejemplos con Ilustraciones y Diagramas
Código Prolog:
padre(juan, carlos).
abuelo(X, Y) :- padre(X, Z), padre(Z, Y).
4. Ejercicios Guiados Paso a Paso

Problema: Representar en álgebra declarativa la regla: 'Un usuario tiene acceso de administrador si es del departamento de TI y tiene autorización firmada'.

admin(U) :- depto(U, ti), autorizado(U).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Escribe en formato de regla declarativa: 'Un servidor está en peligro si tiene el puerto 22 abierto y la contraseña es débil'. Pista: peligro(S) :- puerto(S, 22), pass_debil(S).

3.4

Inducción Matemática y Demostraciones

1. Explicación Teórica y Conceptual

La Inducción Matemática es una técnica de demostración formal para proposiciones que involucran números naturales \(\mathbb{N}\). Funciona como el efecto dominó: si se demuestra el caso base \(P(1)\) y se prueba que la veracidad en \(k\) implica la veracidad en \(k+1\), queda demostrado para todos los enteros positivos. Es clave para validar algoritmos recursivos.

2. Glosario de Términos y Definiciones
  • • Paso Base: Verificar que la proposición \(P(n)\) es cierta para el caso inicial \(n = 1\).
  • • Hipótesis de Inducción: Asumir como verdadera la proposición para un entero arbitrario \(n = k\) (\(P(k)\)).
  • • Paso Inductivo: Demostrar que bajo la hipótesis \(P(k)\), la proposición es verdadera para \(n = k + 1\) (\(P(k+1)\)).
3. Ejemplos con Ilustraciones y Diagramas
Fórmula Clásica de Sumatoria de Gauss:
1 + 2 + 3 + ... + n = [ n(n + 1) ] / 2
4. Ejercicios Guiados Paso a Paso

Problema: Demostrar por inducción que \(1 + 2 + \dots + n = \frac{n(n+1)}{2}\).

1. Base (\(n=1\)): \(1 = \frac{1(2)}{2} = 1\) (Cumple).
2. Hipótesis: \(1 + \dots + k = \frac{k(k+1)}{2}\).
3. Paso (\(k+1\)): \(1 + \dots + k + (k+1) = \frac{k(k+1)}{2} + (k+1) = \frac{k(k+1) + 2(k+1)}{2} = \frac{(k+1)(k+2)}{2}\).
Queda demostrado para todo \(n \ge 1\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Demuestra por inducción matemática que la suma de los primeros \(n\) números impares es \(n^2\) (\(1 + 3 + 5 + \dots + (2n-1) = n^2\)). Pista: \(k^2 + 2k + 1 = (k+1)^2\).

3.5

Aplicaciones de la Lógica en la Computación

1. Explicación Teórica y Conceptual

La lógica matemática es el lenguaje formal detrás del diseño de compiladores, sistemas de verificación formal de código crítico (aviónica, sistemas bancarios), optimización de consultas en motores de bases de datos y la estructuración de condiciones de parada en algoritmos iterativos y recursivos.

2. Glosario de Términos y Definiciones
  • • Verificación Formal: Demostración matemática de que un programa cumple sus especificaciones sin errores de ejecución.
  • • Cortocircuito Lógico: Optimización en lenguajes donde A && B no evalúa B si A es falso.
  • • Invariante de Bucle: Condición lógica que se mantiene verdadera antes y después de cada iteración de un ciclo while.
3. Ejemplos con Ilustraciones y Diagramas
Invariante de Bucle en Código:
/* Invariante: suma = Σ array[0..i-1] */
for(int i=0; i<n; i++) { suma += array[i]; }
4. Ejercicios Guiados Paso a Paso

Problema: Analizar si la expresión condicional if (x > 0 || (x <= 0 && y > 5)) puede simplificarse lógicamente.

Definiendo \(P: x > 0\), \(Q: y > 5\). La expresión es \(P \lor (\neg P \land Q)\). Por ley distributiva: \((P \lor \neg P) \land (P \lor Q) \equiv 1 \land (P \lor Q) \equiv P \lor Q\).
Código simplificado: if (x > 0 || y > 5).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Simplifica la condición lógica if (!(a && !b) && !b). Pista: \(\neg b \land \neg a\).

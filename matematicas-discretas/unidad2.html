2.1

Características de los Conjuntos y Conjunto Potencia

1. Explicación Teórica y Conceptual

La Teoría de Conjuntos formaliza la noción de colección de elementos distintos sin orden. Es la base conceptual de las bases de datos relacionales y el tipado de datos en lenguajes de programación. Si un conjunto \(A\) contiene \(n\) elementos, el Conjunto Potencia \(\mathcal{P}(A)\) contiene todas las posibles agrupaciones con cardinalidad exacta \(|\mathcal{P}(A)| = 2^n\).

2. Glosario de Términos y Definiciones
  • • Conjunto Universo (\(U\)): Conjunto referencial que contiene todos los elementos del contexto de estudio.
  • • Conjunto Vacío (\(\emptyset\)): Conjunto que no contiene elementos (\(|\emptyset| = 0\)). Es subconjunto de todo conjunto.
  • • Conjuntos Numéricos: \(\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}\).
  • • Conjunto Potencia \(\mathcal{P}(A)\): \(\mathcal{P}(A) = \{X \mid X \subseteq A\}\), con \(|\mathcal{P}(A)| = 2^n\).
3. Ejemplos con Ilustraciones y Diagramas

4. Ejercicios Guiados Paso a Paso

Problema: Determinar el conjunto potencia de \(S = \{1, 2, 3\}\) y verificar su cardinalidad.

1. Cardinalidad: \(n = 3 \implies 2^3 = 8\) elementos.
2. Subconjuntos de tamaño 0: \(\emptyset\).
3. Tamaño 1: \(\{1\}, \{2\}, \{3\}\).
4. Tamaño 2: \(\{1, 2\}, \{1, 3\}, \{2, 3\}\).
5. Tamaño 3: \(\{1, 2, 3\}\).
\(\mathcal{P}(S) = \{\emptyset, \{1\}, \{2\}, \{3\}, \{1,2\}, \{1,3\}, \{2,3\}, \{1,2,3\}\}\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Si un conjunto \(B\) tiene 5 elementos, ¿cuántos elementos tiene su conjunto potencia \(\mathcal{P}(B)\)? Escribe al menos 4 subconjuntos. Pista: \(2^5 = 32\) subconjuntos.

2.2

Operaciones con Conjuntos y Diagramas de Venn

1. Explicación Teórica y Conceptual

Las operaciones sobre conjuntos combinan o transforman colecciones de elementos generando nuevos conjuntos. Los Diagramas de Venn son herramientas geométricas visuales donde el rectángulo representa el universo \(U\) y los círculos representan los conjuntos, permitiendo sombreados específicos para cada operación booleana.

2. Glosario de Términos y Definiciones
  • • Unión (\(A \cup B\)): \(\{x \mid x \in A \lor x \in B\}\).
  • • Intersección (\(A \cap B\)): \(\{x \mid x \in A \land x \in B\}\).
  • • Complemento (\(A'\)): \(\{x \in U \mid x \notin A\}\).
  • • Diferencia (\(A - B\)): \(\{x \mid x \in A \land x \notin B\}\).
  • • Diferencia Simétrica (\(A \oplus B\)): \((A \cup B) - (A \cap B)\).

4. Ejercicios Guiados Paso a Paso

Problema: Sean \(U = \{1, 2, 3, 4, 5, 6\}\), \(A = \{1, 2, 3, 4\}\) y \(B = \{3, 4, 5\}\). Calcular \(A \cup B\), \(A \cap B\), \(A - B\) y \(A \oplus B\).

• \(A \cup B = \{1, 2, 3, 4, 5\}\)
• \(A \cap B = \{3, 4\}\)
• \(A - B = \{1, 2\}\)
• \(A \oplus B = \{1, 2, 5\}\).

5. Ejercicios de Práctica Propuestos para Alumnos (Firmas 40%)

1. Sean \(A = \{a, b, c, d\}\) y \(B = \{c, d, e, f\}\). Determina \(A \oplus B\) y \(B - A\). Pista: \(A \oplus B = \{a, b, e, f\}\), \(B - A = \{e, f\}\).

2.3

Propiedades de los Conjuntos (Leyes de De Morgan e Inclusión-Exclusión)

1. Explicación Teórica y Conceptual

Las propiedades de los conjuntos rigen el comportamiento de las operaciones algebraicas. Destacan las Leyes de De Morgan, que establecen la dualidad entre unión e intersección bajo complementación, y el Principio de Inclusión-Exclusión, fundamental en combinatoria y conteo probabilístico para evitar duplicidades.

2. Glosario de Términos y Definiciones
  • • Leyes de De Morgan: \((A \cup B)' = A' \cap B'\) y \((A \cap B)' = A' \cup B'\).
  • • Distributiva: \(A \cap (B \cup C) = (A \cap B) \cup (A \cap C)\).
  • • Principio de Inclusión-Exclusión: \(|A \cup B| = |A| + |B| - |A \cap B|\).
3. Ejemplos con Ilustraciones y Diagramas
Principio de Inclusión-Exclusión para 3 Conjuntos
|A ∪ B ∪ C| = Σ|A| - Σ|A ∩ B| + |A ∩ B ∩ C|
4. Ejercicios Guiados Paso a Paso

Problema: En una encuesta a 100 estudiantes de sistemas, 60 programan en Java, 45 programan en Python y 20 programan en ambos. ¿Cuántos estudiantes programan en al menos uno de los dos lenguajes?

Aplicando Inclusión-Exclusión: \(|J \cup P| = |J| + |P| - |J \cap P| = 60 + 45 - 20 = 85\) estudiantes.

2.4

Aplicaciones de los Conjuntos en la Computación

1. Explicación Teórica y Conceptual

En ciencias computacionales, los conjuntos son la base de los modelos de Bases de Datos Relacionales (SQL), donde las consultas algebraicas operan sobre conjuntos de tuplas mediante cláusulas como UNION, INTERSECT y EXCEPT, así como en estructuras de datos optimizadas con búsquedas \(O(1)\) basadas en Hash Sets.

2. Glosario de Términos y Definiciones
  • • Relación SQL: Conjunto de registros (tuplas) con atributos definidos.
  • • HashSet: Colección en Java/Python donde cada inserción es única mediante funciones hash.
  • • JOIN en SQL: Producto cartesiano filtrado por predicados de igualdad de conjuntos.

4. Ejercicios Guiados Paso a Paso

Problema: Un sistema de control escolar tiene el conjunto de inscritos en Taller A \(\{101, 102, 103\}\) y en Taller B \(\{102, 103, 104\}\). ¿Cómo se obtienen los alumnos inscritos exclusivamente en el Taller A?

Se aplica la diferencia de conjuntos: \(A - B = \{101\}\) (Cláusula SQL: SELECT id FROM TallerA EXCEPT SELECT id FROM TallerB;).
